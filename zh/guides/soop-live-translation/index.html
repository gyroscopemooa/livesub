REAL-TIME TRANSLATION GUIDE

如何实时翻译 SOOP (AfreecaTV)

Follow SOOP (formerly AfreecaTV) streams across languages — Transtream translates the browser audio into live subtitles.

开始使用 Transtream ↗

准备工作

  • 在电脑浏览器标签页中打开 SOOP (AfreecaTV)
  • 在另一个标签页或窗口中打开 Transtream
  • 想要的字幕语言

设置步骤

  1. 在电脑浏览器中打开 SOOP (AfreecaTV)。
  2. 打开 Transtream 并开始翻译会话。
  3. 选择 SOOP (AfreecaTV) 标签页（或系统音频）作为音频来源。
  4. 选择说话语言和字幕语言。
  5. 把字幕面板放在不遮挡播放器的位置。

使用技巧

  • Use a wide window instead of fullscreen so the subtitle panel sits beside the player.
  • If several streams are open, select only the tab you want subtitled.

字幕没有出现时

请确认所选标签页确实有声音、没有静音，并且浏览器的音频共享权限已开启。如果重新打开了标签页，需要重新连接音频来源。

常见问题

翻译 SOOP (AfreecaTV) 需要安装应用吗？

不需要。Transtream 在浏览器中运行，使用你所选标签页的音频。

会录制 SOOP (AfreecaTV) 吗？

不会。它只显示会话中共享音频的翻译字幕，不会录制、下载或再分发任何内容。

支持哪些语言？

支持中文、英语、日语、西班牙语等 40 多种语言，说话语言和字幕语言可分别选择。

SOOP (AfreecaTV) 是其各自所有者的商标。Transtream 和 live sub 与 SOOP (AfreecaTV) 没有关联，也未获其认可。
