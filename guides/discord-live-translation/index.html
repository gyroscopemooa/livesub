디스코드 실시간 번역 자막 켜는 법

해외 친구들과의 디스코드 음성 채널이나 게임 중 통화를 Transtream 실시간 번역 자막으로 따라가 보세요. 브라우저 버전 디스코드에서 사용하기 가장 쉽습니다.

Transtream 시작하기 ↗

준비물

  • 디스코드을 연 PC(데스크톱) 브라우저 탭
  • 다른 탭이나 창에서 연 Transtream
  • 번역해서 볼 자막 언어

설정 방법

  1. PC 브라우저에서 디스코드 회의을 엽니다.
  2. Transtream을 열고 번역 세션을 시작합니다.
  3. 오디오 소스로 디스코드 탭(또는 시스템 오디오)을 선택합니다.
  4. 말하는 언어와 자막 언어를 고릅니다.
  5. 자막 패널을 플레이어나 화면을 가리지 않는 위치에 둡니다.

더 잘 쓰는 팁

  • discord.com 웹 버전으로 접속하면 탭 오디오를 선택할 수 있습니다.
  • 여러 명이 동시에 말하면 번역이 섞일 수 있습니다.

자막이 나오지 않을 때

선택한 탭에서 실제로 소리가 나는지, 탭이 음소거되어 있지 않은지, 브라우저의 오디오 공유 권한이 켜져 있는지 확인하세요. 탭을 새로 열었다면 오디오 소스를 다시 연결해야 합니다.

자주 묻는 질문

디스코드 번역은 앱 설치가 필요한가요?

아니요. Transtream은 브라우저에서 동작하며, PC 브라우저에서 재생 중인 탭의 오디오를 선택해 사용합니다.

디스코드 음성을 녹화하거나 저장하나요?

Transtream은 세션에 공유된 오디오를 번역 자막으로 보여 줄 뿐, 방송이나 회의를 녹화·다운로드·재배포하지 않습니다.

어떤 언어로 번역할 수 있나요?

한국어, 영어, 일본어, 스페인어 등 40개 이상의 언어를 지원합니다. 말하는 언어와 자막 언어를 각각 선택할 수 있습니다.

디스코드은(는) 해당 소유자의 상표입니다. Transtream과 live sub는 디스코드와 제휴하거나 승인받은 서비스가 아닙니다.
